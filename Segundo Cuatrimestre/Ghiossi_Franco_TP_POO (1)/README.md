# ☕ Trabajo Práctico: Fundamentos de Programación Orientada a Objetos (POO)

Este repositorio contiene la resolución de la guía práctica sobre los pilares y fundamentos de la **Programación Orientada a Objetos (POO)** en **Java**, desarrollada para la **Tecnicatura Universitaria en Programación (UTN)** 🇦🇷.

El proyecto está diseñado para afianzar conceptos clave como la abstracción de entidades del mundo real, la creación de clases, la manipulación de estados internos a través de atributos y el comportamiento mediante métodos específicos.

---

## 🛠️ Tecnologías y Herramientas
* **Lenguaje:** Java (JDK 8 o superior).
* **Entorno de Desarrollo (IDE):** Apache NetBeans sobre entorno Linux.
* **Foco de Estudio:** Lógica de negocio, diseño de clases y encapsulamiento.

---

## 📂 Estructura de Ejercicios Resueltos

El código fuente está modularizado en paquetes independientes que abordan diferentes niveles de lógica y diseño:

* **📦 Ejercicio_01 (Gestión de Datos):** Implementación de la clase `Estudiante` para comprender el modelado de atributos básicos, constructores y métodos de acceso (*getters* y *setters*).
* **📦 Ejercicio_02 (Operaciones Lógicas):** Desarrollo de una `Calculadora` funcional basada en el paso de parámetros y retorno de métodos aritméticos.
* **📦 Ejercicio_03 (Control de Estado):** Creación de un `Contador` mecánico/digital para experimentar con la mutabilidad de estados internos (incremento, decremento y reseteo).
* **📦 Ejercicio_04 (Simulación Dinámica):** Modelado interactivo de una `Gallina`, aplicando reglas de negocio lúdicas para simular ciclos de comportamiento específicos.
* **📦 Ejercicio_05 (Simulación Avanzada):** Diseño de una `NaveEspacial` donde se manipulan múltiples variables críticas (como propulsión, velocidad o recursos) para simular el comportamiento de un sistema complejo por consola.

---

## 📐 Conceptos Clave Implementados
* **Abstracción:** Capacidad de aislar las propiedades y comportamientos esenciales de los objetos (desde una calculadora hasta una nave espacial).
* **Encapsulamiento:** Protección de datos internos mediante modificadores de acceso restringidos (`private`) expuestos de manera segura.
* **Constructores Parametrizados:** Inicialización controlada de objetos al momento de su instanciación en memoria.
